# Vazirmatn

[Vazirmatn 33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003), by the Vazirmatn Project Authors, is licensed under the [SIL Open Font License 1.1](OFL.txt). See [AUTHORS.txt](AUTHORS.txt).

The complete supplied static TTF set is preserved in `ttf/`. The WOFF2 files are compressed copies of its Regular (400), Medium (500), SemiBold (600), and Bold (700) weights, generated with FontTools without subsetting or changing glyphs. Only WOFF2 files and license notices are copied into the website build; ordinary builds need no font tools or network requests.

The CSS limits Vazirmatn to Arabic-script Unicode ranges for Dari/Pashto interface text. Latin text uses the existing system font stack.
